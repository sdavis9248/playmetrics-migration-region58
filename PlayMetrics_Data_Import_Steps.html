Birth Certificate Verification Split

This is what makes your import more valuable than starting fresh. Previously verified players won't need to re-upload their birth certificate.

💡 Key Finding from Webinar (Section 3) "You also have the ability to import previous player birth certificate verifications... you can import players and designate that those players have previously had their birth certificate verified."

Add the BC status from the original Enrollment Details to the exported CSV:

BC StatusAction
VerifiedFlag as verified in import — player won't be prompted again
UnverifiedInclude — they'll need to re-upload during registration
No File UploadedInclude — prompted during registration via your BC player question

Send Invites to Imported Families

Once players are imported, you can send invite emails from PlayMetrics. The invite is tied to the email address on record — the parent clicks it, creates or connects their PlayMetrics account, and the player record links to them automatically.

💡 Your Key Discovery Post-import invites are tied to the original email on record. This eliminates the account-mismatch risk that PM originally warned about. This is why importing is safe despite their "start fresh" recommendation.

Path: Players (club admin sidebar) → select imported players → invite action (visible once players exist in the current season)

Post-Launch: Volunteer Import (Later)

Volunteer data import doesn't block registration. Handle this after go-live when you have bandwidth. The full volunteer compliance workflow is documented separately.

High-Level Volunteer Import Steps

1. Add "Volunteer" label under Club Settings and enable Co-Ed Teams.
2. Update Team Staff Titles to standardized AYSO roles (Head Coach, Assistant Coach, Team Manager, Board Member, Clerical, Concessions, Field Prep, Fund Raising, Referee, Team Parent).
3. Import Volunteer team shells using the AYSO Pilot Import Template.
4. Hide all Volunteer teams (Teams → More Actions → Set Visibility → Filter by "Volunteer" → Uncheck all roles).
5. Export volunteers from your Core Program and Volunteer Sign Up.
6. Map them into the Team Staff Import File (name, email, phone, team name, season).
7. Upload via Staff → Team Staff → More Actions → Import Team Staff.
8. Import staff into Governing System to trigger compliance emails.

Quick Reference: CLI Commands
# Preview player counts by division
python main.py --playmetrics-preview

# Export all players to PlayMetrics CSV
python main.py --playmetrics-players

# Export with specific enrollment file
python main.py --playmetrics-players --playmetrics-file data/Enrollment_Details_cleaned.xlsx

# Export only team-assigned players (post-draft)
python main.py --playmetrics-players --exclude-unallocated

# Export coaches (always specify team-info-file)
python main.py --playmetrics-coaches --team-info-file data/downloads/TeamInfo.xlsx

# Download team info report from SC
python main.py TEAM_INFO
